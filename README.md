# Site Factory

Local-first workspace for building landing pages, SEO pages, blog drafts, AI model portfolio pages, WordPress-ready drafts, and future service prototypes with Codex.

This project intentionally does not connect to Bluehost, WordPress, OpenAI, or paid external APIs. Everything starts as local files that are safe to review, commit, and evolve.

## Run Locally

```powershell
npm.cmd install
npm.cmd run dev
```

Open `http://localhost:3000`.

## Useful Commands

```powershell
npm.cmd run typecheck
npm.cmd run build
npm.cmd test
npm.cmd run seo:audit
npm.cmd run sitemap:generate
```

## Deployment Status

The repository includes Vercel-ready build configuration, but deployment is intentionally manual and not connected.
